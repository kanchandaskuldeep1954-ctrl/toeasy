# Toeasy Pilot Conversion Checklist (Day 0 -> Day 90)

## 1) Pilot Package Definition
- Offer: `Decision Room Pilot (90 days)`.
- Pricing band: `$1.5k-$3k/month` (`$2k` target midpoint).
- Optional onboarding fee: `$1k`.
- Included:
  - Studio-first setup (`Sheets + Postgres/MySQL + Slack`)
  - 1 RevOps weekly playbook template
  - Evidence-first report + action sync workflow
  - Weekly KPI/ROI review with customer champion

## 2) Contract and Commercial Artifacts
- [ ] Pilot SOW template finalized.
- [ ] MSA + DPA baseline reviewed.
- [ ] Order form with pilot scope + seat assumptions.
- [ ] Day-60 annual conversion order form ready.
- [ ] Annual pricing tiers documented:
  - `Starter`: `$15k/year`
  - `Growth`: `$20k/year`
  - `Scale`: `$24k/year`

## 3) Delivery and Success Artifacts
- [ ] Onboarding checklist:
  - workspace bootstrap
  - connector setup
  - first room creation
  - first report publish
- [ ] Weekly success review template.
- [ ] KPI baseline worksheet:
  - time-to-insight
  - insight-to-action
  - manual update reduction
  - evidence coverage ratio
- [ ] Incident/reliability escalation runbook.

## 4) Product Proof Assets for Conversion
- [ ] ROI dashboard screenshot pack for each pilot account.
- [ ] Case-study snapshot generator output captured at weeks 4/8/12.
- [ ] Before/after workflow evidence:
  - manual status effort delta
  - cycle-time delta
  - publish reliability trend
- [ ] Reference architecture and security FAQ one-pager.

## 5) Day-60 Conversion Motion
- [ ] Executive readout deck generated from pilot telemetry.
- [ ] Business case summary:
  - quantified ops hours saved
  - decision latency reduction
  - evidence coverage improvement
- [ ] Expansion map:
  - additional rooms
  - additional owner groups
  - automation schedule expansion
- [ ] Commercial proposal sent by day 60.

## 6) Day-90 Exit Outcomes
- [ ] `Convert` to annual (`target >=35% of pilots`), or
- [ ] `Extend` pilot with explicit gap/action plan, or
- [ ] `Exit` with postmortem + product learning capture.

## 7) Internal Ownership Matrix
- PM: pilot outcomes + conversion narrative.
- Engineering: reliability, quality gates, integration health.
- Design: onboarding clarity + persona fit.
- Customer success: weekly cadence + stakeholder alignment.
- Founder/GTM lead: commercial close and annual negotiation.

## 8) Weekly Operating Rhythm
- Monday: telemetry review + open risks.
- Wednesday: customer success check-in.
- Friday: pilot scorecard + conversion readiness update.
