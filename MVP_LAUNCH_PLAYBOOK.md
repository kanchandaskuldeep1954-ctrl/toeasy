# Toeasy Decision Room MVP Launch Playbook

## Product Scope (MVP)
- Product surface: `Decision Room Studio` only.
- Core flow: `Connect -> Analyze -> Brief -> Actions -> Slack Sync -> Status Draft`.
- Supported data inputs: `Google Sheets` + `SQL connector (Postgres/MySQL)`.
- Required trust model: all actions must have evidence lineage before sync.

## Target Customer
- Segment: SMB RevOps teams (`20-200 employees`, `1-5 analysts`).
- Buyer: Head of RevOps / Ops Manager.
- User loop: analyst runs analysis, manager approves actions, exec consumes digest.

## Commercial Offer
- Offer name: `Decision Room Pilot (90 days)`.
- Price target: `$2,000/month` (test band `$1,500-$3,000`).
- Optional onboarding fee: `$1,000`.
- Pilot includes:
  - environment setup
  - 1 weekly RevOps workflow template
  - Slack handoff + status draft
  - weekly success review

## 16-Week Execution Cadence
- Weeks 1-2: simplify navigation and guided flow.
- Weeks 3-6: reliability hardening and artifact/lineage consistency.
- Weeks 7-10: action sync, status draft automation, ownership board.
- Weeks 11-13: paid design-partner onboarding and KPI instrumentation.
- Weeks 14-16: conversion assets (pricing page, ROI calculator, case studies).

## Success Metrics
- Time-to-first-insight median: `<30 minutes`.
- Time from insight to assigned action: `<24 hours`.
- Manual status update reduction: `>=50%`.
- Weekly active rooms: `>=60%`.
- Evidence coverage for decisions: `>=80%`.
- Pilot-to-annual conversion by day 90: `>=35%`.
